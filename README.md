# Imashi Sandeepika - Data Analyst Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS, showcasing data analysis expertise and professional experience.

## Features

- **Modern Design**: Clean, professional UI with data visualization theme
- **Responsive Layout**: Fully responsive design that works on all devices
- **Smooth Animations**: Framer Motion animations for enhanced user experience
- **Interactive Components**: Dynamic contact form and interactive elements
- **SEO Optimized**: Meta tags and structured content for better search visibility
- **Performance Focused**: Built with Vite for fast development and optimized builds

## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Charts**: Chart.js + React Chart.js 2
- **Build Tool**: Vite
- **Development**: ESLint + TypeScript ESLint

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/imashi-sandeepika/my-portfolio.git
cd my-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Customization

### Colors
The color scheme can be customized in `tailwind.config.js`:
- Primary colors: Blue theme for professional look
- Secondary colors: Gray scale for text and backgrounds

### Content
Update the content in each component file:
- Personal information in `Hero.tsx`
- Professional bio in `About.tsx`
- Skills and experience in respective components
- Contact information in `Contact.tsx`

### Animations
Framer Motion animations can be customized in each component. Key animation patterns:
- Fade in on scroll
- Slide animations
- Stagger effects for lists

## Responsive Design

The portfolio is fully responsive with breakpoints:
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
